# Computer Science
**Technical Notes**
**Author:** Rodrigo Kang

This directory contains systematic notes on computer science, with an emphasis on the theoretical foundations, computational principles, and methods underlying the design and analysis of algorithms and computational systems.

The notes develop fundamental concepts alongside their practical implementation, connecting abstract models of computation with algorithms, data structures, software, and computational problem solving.

## Scope

The material may cover topics such as algorithms and data structures, computational complexity, programming paradigms, computer architecture, operating systems, databases, distributed systems, networks, software engineering, and theoretical computer science.

Particular attention is given to the principles that determine how computational problems are represented, decomposed, and solved, as well as to the efficiency, correctness, and scalability of computational methods.

## Approach

The notes are developed from first principles where this helps clarify the structure of a computational problem or the reasoning behind a method. Theoretical concepts are complemented by algorithms, implementations, and computational experiments where appropriate.

The emphasis is not only on implementing solutions, but also on understanding:

* how computational problems are formulated and represented;
* the principles underlying algorithms and data structures;
* how correctness and computational complexity are analysed;
* the trade-offs involved in algorithm and system design;
* how abstractions translate into practical implementations;
* how computational resources affect the choice of a solution; and
* where particular methods, abstractions, or architectures become inappropriate.
