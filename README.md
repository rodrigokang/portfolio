# Data Science Across Domains

### From Methods and Models to Business Applications

**Read the portfolio online:**  
[Data Science Across Domains – Portfolio Website](https://rodrigokang.github.io/portfolio)

---

This repository contains the materials for **Data Science Across Domains**, a portfolio of applied data science projects presented in book form. It documents how quantitative reasoning, statistical modeling, machine learning, and computational methods can be combined to address real-world problems across a variety of application domains.

Rather than presenting isolated notebooks or disconnected examples, the portfolio is organized as a series of **self-contained case studies**. Each project begins with a clearly defined problem and progresses through modeling decisions, implementation, evaluation, and discussion of limitations. Together, the projects illustrate a consistent approach to quantitative problem solving rather than a catalogue of algorithms or techniques.

The repository is organized into two main components: the written portfolio and the accompanying computational artifacts.

---

## Repository Structure

### Book

The written portfolio is developed using **Quarto** and presented as a technical book. Each chapter documents an independent applied data science project, allowing readers to explore the portfolio sequentially or navigate directly to topics of interest.

Most projects follow a common structure:

* Problem definition and context
* Modeling approach
* Methodology and implementation
* Results, discussion, and limitations
* Technical appendix (when appropriate)

The emphasis throughout is on disciplined modeling, transparent assumptions, careful evaluation, and practical implementation. Mathematical concepts are introduced only when they support modeling decisions or improve understanding of the proposed approach.

---

### Code

[Notebooks and Scripts](./notebooks-and-scripts)

This directory contains the computational artifacts accompanying the projects presented throughout the portfolio.

Depending on the nature of each project, the material may include:

* **Jupyter notebooks** implementing data processing, modeling, experimentation, and evaluation workflows in Python
* **R scripts** supporting statistical analysis, exploratory data analysis, visualization, and complementary implementations

The programming language and computational workflow are selected according to the requirements of each project rather than following a fixed implementation strategy.

---

## Purpose of the Portfolio

This portfolio reflects a practical approach to applied data science. The emphasis is not on demonstrating the largest possible collection of algorithms or following technological trends, but on showing how quantitative reasoning, statistical modeling, and computational methods can be applied to develop reliable solutions to real-world problems.

Across different application domains, the same underlying philosophy remains consistent: understand the problem, make assumptions explicit, select methods that are appropriate to the task, and evaluate results carefully before drawing conclusions.
