Sediment Source Modeling with Sandoval-Style Ratio Deconvolution¶

AUTHOR
Rodrigo Kang

Overview¶

This notebook implements a Sandoval-style ratio-based deconvolution workflow for the Sediment Source Modeling project.

The goal is to estimate the source fractions of artificial sediment mixtures using pairwise tracer ratios rather than matching tracer concentrations directly. The workflow is intentionally separated from the stochastic sediment fingerprinting notebook and from the McCaffrey-style constrained least-squares notebook so that the ratio-based approach can be evaluated as an independent deterministic baseline.

Unlike probabilistic source apportionment models, this method produces point estimates only. Its value is comparative and diagnostic: it tests whether relationships among selected tracers are sufficient to recover source proportions when the mixture problem is formulated in ratio space.

Data Loading¶

The notebook uses the sediment fingerprinting data from the main project:

  • mixture_proportions.csv: known source proportions for the artificial mixtures.
  • fingerprint_data.csv: geochemical and colour fingerprint measurements for source samples and laboratory mixtures.
  • selected_tracers.csv: tracer variables selected for source apportionment.

The ratio-based model is fitted in the positive tracer-concentration scale. When raw files are available, the selected tracers are read directly from the original data. If only the previously prepared log-transformed inputs are available, the notebook exponentiates them before constructing tracer ratios. This avoids taking ratios of logarithms, which would not preserve the original geochemical meaning of the measurements.

    data_dir: Path,
    input_processed_dir: Path,
    source_order: list[str],

    Outputs:
    tuple[pd.DataFrame, pd.DataFrame, pd.DataFrame, list[str]]
        Source data, mixture data, true proportions, and selected tracer names.

    Author:
    Rodrigo Kang
    """
    raw_files_exist = all([
        (data_dir / "mixture_proportions.csv").exists(),
        (data_dir / "fingerprint_data.csv").exists(),
        (data_dir / "selected_tracers.csv").exists(),
    ])

    if raw_files_exist:
        proportions_raw = pd.read_csv(data_dir / "mixture_proportions.csv")
        fingerprints = pd.read_csv(data_dir / "fingerprint_data.csv")
        selected_tracers = pd.read_csv(data_dir / "selected_tracers.csv")["x"].tolist()

        source_name_map = {
            "source_s": "Subsurface",
            "source_d": "Decontaminated",
            "source_pf": "Cropland",
            "source_f": "Forest",
        }

        proportions = proportions_raw.rename(columns={
            "sediment_sample": "sample",
            "source_S": "Subsurface",
            "source_D": "Decontaminated",
            "source_PF": "Cropland",
            "source_F": "Forest",
        })
        proportions[source_order] = proportions[source_order].astype(float)

        sources = fingerprints.query("type == 'source'").copy()
        targets = fingerprints.query("type == 'target'").copy()

        sources["source_label"] = sources["source"].str.lower().map(source_name_map)

        if (fingerprints[selected_tracers] <= 0).any().any():
            raise ValueError("Selected tracers must be positive for ratio-based modelling.")

        source_df = sources[["sample", "source", "source_label"] + selected_tracers].copy()
        target_df = targets[["sample"] + selected_tracers].copy()

        truth = pd.concat([
            targets[["sample"]].reset_index(drop=True),
            proportions[source_order].reset_index(drop=True),
        ], axis=1)

    else:
        required_files = [
            input_processed_dir / "source_log_data.csv",
            input_processed_dir / "laboratory_mixture_log_data.csv",
            input_processed_dir / "known_source_proportions.csv",
        ]

        missing_files = [path.name for path in required_files if not path.exists()]
        if missing_files:
            raise FileNotFoundError(
                "Could not find raw input files or prepared log-transformed inputs. "
                f"Missing files: {missing_files}"
            )

        source_log_df = pd.read_csv(input_processed_dir / "source_log_data.csv")
        target_log_df = pd.read_csv(input_processed_dir / "laboratory_mixture_log_data.csv")
        truth = pd.read_csv(input_processed_dir / "known_source_proportions.csv")

        selected_tracers = [
            column for column in target_log_df.columns
            if column != "sample"
        ]

        source_df = source_log_df.copy()
        target_df = target_log_df.copy()
        source_df[selected_tracers] = np.exp(source_df[selected_tracers])
        target_df[selected_tracers] = np.exp(target_df[selected_tracers])

    return source_df, target_df, truth, selected_tracers

Sandoval-Style Preprocessing¶

The Sandoval-style workflow represents each source by a characteristic tracer signature and compares mixtures through pairwise tracer ratios. Because ratios are sensitive to zeros and sign changes, the analysis uses the positive tracer-concentration scale.

A tracer-wise scaling step is applied before deconvolution. Each tracer is divided by the largest representative source value for that tracer. This keeps the numerical range stable while preserving the ratios used by the objective function, because the same scaling is applied to source and mixture signatures.

Ratio-Based Constrained Deconvolution¶

For each artificial mixture, the source fractions are estimated by minimizing the mismatch between observed and predicted pairwise tracer ratios.

If $A$ contains the representative source signatures, $b$ is the observed mixture signature, and $x$ is the vector of source fractions, the predicted mixture signature is:

$$ \hat{b} = Ax $$

The objective is defined in log-ratio space:

$$ \min_x \sum_{i<j}\left[\log\left(\frac{\hat{b}_i}{\hat{b}_j}\right) - \log\left(\frac{b_i}{b_j} \right) \right]^2 $$

subject to:

$$ x_k \geq 0, \qquad \sum_k x_k = 1 $$

This formulation is deterministic, constrained to the simplex, and less dependent on absolute tracer magnitudes than direct least-squares deconvolution.

def pairwise_log_ratios(values: np.ndarray, eps: float = 1e-12) -> np.ndarray:
    """
    Build pairwise log ratios for a positive tracer vector.

    Brief explanation:
    Compute log(v_i / v_j) for all pairs i < j. A small epsilon is used only as
    numerical protection against division by zero.

    Inputs:
    -------
    values : np.ndarray
        Positive tracer vector.
    eps : float
        Minimum value used for numerical stability.

    Outputs:
    --------
    np.ndarray
        Pairwise log-ratio vector.

    Author:
    -------
    Rodrigo Kang
    """
    values = np.clip(np.asarray(values, dtype=float), eps, None)
    idx_i, idx_j = np.triu_indices(values.size, k=1)
    return np.log(values[idx_i]) - np.log(values[idx_j])


def estimate_sandoval_fractions(
    source_matrix: np.ndarray,
    target_vector: np.ndarray,
    n_random_starts: int = 20,
    random_state: np.random.Generator | None = None,
) -> tuple[np.ndarray, float, np.ndarray, np.ndarray]:
    """
    Estimate source fractions using Sandoval-style ratio deconvolution.

    Brief explanation:
    Solve a constrained optimization problem in pairwise log-ratio space. Multiple
    starting points are used because the ratio objective is not guaranteed to be
    globally convex.

    Inputs:
    -------
    source_matrix : np.ndarray
        Matrix with tracers in rows and sources in columns.
    target_vector : np.ndarray
        Mixture tracer vector.
    n_random_starts : int
        Number of random initial compositions used in addition to deterministic starts.
    random_state : np.random.Generator | None
        Random number generator used for reproducible starts.

    Outputs:
    --------
    tuple[np.ndarray, float, np.ndarray, np.ndarray]
        Estimated fractions, objective value, predicted mixture vector, and ratio residuals.

    Author:
    -------
    Rodrigo Kang
    """
    if random_state is None:
        random_state = np.random.default_rng(42)

    n_sources = source_matrix.shape[1]
    observed_ratios = pairwise_log_ratios(target_vector)

    def objective(fractions: np.ndarray) -> float:
        predicted = source_matrix @ fractions
        predicted_ratios = pairwise_log_ratios(predicted)
        residual = predicted_ratios - observed_ratios
        return float(np.mean(residual ** 2))

    constraints = {
        "type": "eq",
        "fun": lambda fractions: np.sum(fractions) - 1.0,
    }
    bounds = [(0.0, 1.0)] * n_sources

    starts = [np.full(n_sources, 1.0 / n_sources)]
    starts.extend(np.eye(n_sources) * 0.85 + 0.15 / n_sources)
    starts.extend(random_state.dirichlet(np.ones(n_sources), size=n_random_starts))

    best_result = None

    for start in starts:
        result = minimize(
            objective,
            x0=np.asarray(start, dtype=float),
            method="SLSQP",
            bounds=bounds,
            constraints=constraints,
            options={"maxiter": 2000, "ftol": 1e-12},
        )

        if result.success and (best_result is None or result.fun < best_result.fun):
            best_result = result

    if best_result is None:
        raise RuntimeError("Sandoval-style ratio optimisation failed for all initial values.")

    fractions = np.clip(best_result.x, 0.0, 1.0)
    fractions = fractions / fractions.sum()

    predicted = source_matrix @ fractions
    ratio_residuals = pairwise_log_ratios(predicted) - observed_ratios
    objective_value = float(np.mean(ratio_residuals ** 2))

    return fractions, objective_value, predicted, ratio_residuals

Model Evaluation¶

Because the Sandoval-style model is deterministic, the evaluation focuses on point-estimate accuracy rather than uncertainty calibration. The main metrics are mean absolute error, root mean squared error, mean error, Nash-Sutcliffe Efficiency, Aitchison distance, and dominant-source classification accuracy.

Because sediment source apportionment estimates are compositional data constrained to the simplex, the Aitchison distance is also reported as a composition-aware performance metric. The source-level metrics are especially useful because they reveal whether the ratio-based baseline systematically overestimates or underestimates a particular source class.

def nash_sutcliffe_efficiency(observed: np.ndarray, predicted: np.ndarray) -> float:
    """
    Compute Nash-Sutcliffe Efficiency.

    Brief explanation:
    Compare prediction errors against the variance of the observed values.

    Inputs:
    -------
    observed : np.ndarray
        Observed values.
    predicted : np.ndarray
        Predicted values.

    Outputs:
    --------
    float
        Nash-Sutcliffe Efficiency.

    Author:
    -------
    Rodrigo Kang
    """
    numerator = np.sum((observed - predicted) ** 2)
    denominator = np.sum((observed - observed.mean()) ** 2)
    return float(1 - numerator / denominator)


def aitchison_distance(x: Iterable[float], y: Iterable[float], eps: float = 1e-12) -> float:
    """
    Compute Aitchison distance between two compositions.

    Brief explanation:
    Apply the centered log-ratio transform and compute the Euclidean distance
    between transformed compositions.

    Inputs:
    -------
    x : Iterable[float]
        First compositional vector.
    y : Iterable[float]
        Second compositional vector.
    eps : float
        Small value used to avoid log-zero issues.

    Outputs:
    --------
    float
        Aitchison distance.

    Author:
    -------
    Rodrigo Kang
    """
    x = np.clip(np.asarray(x, dtype=float), eps, None)
    y = np.clip(np.asarray(y, dtype=float), eps, None)

    x = x / x.sum()
    y = y / y.sum()

    clr_x = np.log(x) - np.mean(np.log(x))
    clr_y = np.log(y) - np.mean(np.log(y))

    return float(np.linalg.norm(clr_x - clr_y))

Final Remarks¶

The Sandoval-style ratio-based model provides a second deterministic baseline for sediment source apportionment. Instead of matching absolute tracer concentrations directly, it estimates source fractions by matching pairwise relationships among selected tracers.

This formulation is useful because it tests whether relative tracer structure contains enough information to recover the source composition of artificial mixtures. If the method performs well, it suggests that source discrimination is not only driven by absolute concentration levels, but also by stable multivariate relationships among tracers.

At the same time, the method should be interpreted carefully. Pairwise ratios are not independent, and the deterministic formulation does not quantify uncertainty in the estimated source contributions. For that reason, the Sandoval-style model is best used as a complementary baseline alongside the McCaffrey-style constrained least-squares model and the stochastic sediment fingerprinting workflow.
