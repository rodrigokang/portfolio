# Customer Value and Retention Dashboard

Interactive Streamlit dashboard for the portfolio project **Customer Value and Retention**, part of the **Retail Analytics** section of *Data Science Across Domains*.

The app turns the precomputed outputs from the project notebooks into a high-level, decision-oriented retail dashboard. It is designed as a lightweight analytical layer: it does **not** retrain models, query the database, or run the full machine learning pipeline. Instead, it reads the CSV outputs generated by the notebooks and presents them as a practical customer management tool.

## What the dashboard shows

The dashboard is organised around a simple commercial storyline:

1. **Diagnose the customer base**  
   Understand how customers differ in recency, frequency, monetary value and RFM score.

2. **Translate behaviour into action**  
   Use RFM segments to decide which groups should be protected, grown, reactivated, monitored or managed through low-cost lifecycle campaigns.

3. **Prioritise churn risk by value**  
   The churn model output is not shown only as a probability. It is converted into expected revenue at risk, risk deciles and retention action tiers.

4. **Allocate retention and growth investment**  
   CLV predictions are adjusted by churn exposure to help distinguish customers worth defending, customers worth growing, and customers better handled through automated campaigns.

The dashboard is intended to be understandable for both technical and non-technical reviewers. It keeps the machine learning outputs visible, but translates them into operational decisions a retail team could actually use.

## Dashboard sections

### 1. Customer Segmentation

This tab uses the RFM segmentation output to profile the customer base. The previous 3D RFM chart was replaced because it was harder to explain and less useful for decision-making. The tab now includes:

- **Segment Strategy Matrix**: average recency vs average monetary value, with bubble size showing segment size.
- **Revenue Concentration by Segment**: identifies which segments drive the largest share of historical revenue.
- **Customer Base Size with Average Value**: treemap view combining segment size and value.
- **RFM Score Spread by Segment**: shows whether segments are internally consistent or contain wide variation.
- **Frequency vs Value by Segment**: separates frequent low-spend behaviour from high-value patterns.
- **Segment Playbook**: table with suggested business actions by segment.

### 2. Churn Prediction

This tab uses the churn model output to support retention prioritisation. It keeps the predictive modelling angle but focuses on where action can protect value. The tab includes:

- **Retention Priority Matrix**: churn probability vs expected revenue at risk.
- **Retention Workload by Action Tier**: expected revenue exposure by recommended retention tier.
- **Risk Deciles: Predicted vs Observed Churn**: model interpretation view for technical reviewers.
- **Revenue at Risk by Risk Decile**: business impact view for non-technical reviewers.
- **Expected Revenue at Risk by Segment**: segment-level exposure.
- **Retention Workload by Customer Count**: operational workload view.
- **Retention Priority Queue**: customer-level list for targeted action.

### 3. Customer Lifetime Value

This tab uses the CLV output to frame customer value as an investment allocation problem. It includes:

- **Value Investment Matrix**: predicted CLV vs segment churn exposure.
- **Future Value by Investment Tier**: risk-adjusted value by action group.
- **Risk-Adjusted CLV by Value Decile**: shows value concentration.
- **CLV at Risk by Segment**: where future value is exposed to churn.
- **Predicted CLV Distribution by Segment**: explains variation within segments.
- **Customer Profit vs Predicted CLV**: connects near-term profitability with future value.
- **Segment Value Plan**: segment-level action plan.
- **Customer CLV Ranking**: customer-level ranking by risk-adjusted future value.

## Data inputs

The app expects the following CSV files in the local `data/` folder:

```text
data/customer-segmentation.csv
data/customer-churn-prediction.csv
data/customer-clv-prediction.csv
```

These files are precomputed outputs from the notebooks. The dashboard assumes they already contain the customer-level segmentation, churn and CLV results.

For backwards compatibility, the loader also accepts a folder named `datos/` if it exists in an older local copy of the project.

## How to run locally

From the dashboard root folder, create and activate a virtual environment if desired, then install the dependencies:

```bash
pip install -r requirements.txt
```

Run the app with:

```bash
streamlit run app.py
```

The dashboard will open in your browser using Streamlit's local development server.

## Notes for reviewers

This dashboard should be read as the interactive companion to the notebooks, not as a replacement for them. The notebooks contain the full data preparation, modelling and evaluation workflow. The dashboard focuses on the final analytical outputs and presents them in a way that supports retail decision-making:

- Which customer groups should be protected?
- Which segments are commercially exposed to churn?
- Which customers have the highest risk-adjusted future value?
- Where should retention and growth efforts be prioritised?
- Which actions should be manual, targeted or automated?

The design is intentionally pragmatic and aligned with the portfolio's target audience: reviewers who value clear business reasoning, interpretable analytics, and technically credible machine learning outputs.
