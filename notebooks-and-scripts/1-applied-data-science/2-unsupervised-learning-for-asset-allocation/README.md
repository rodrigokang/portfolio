# Unsupervised Learning for Asset Allocation

This repository contains the implementation files accompanying the portfolio project **Unsupervised Learning for Asset Allocation**, part of the book *Data Science Across Domains: From Methods and Models to Business Applications*.

The project explores the use of unsupervised learning techniques for portfolio construction and asset allocation. Principal Component Analysis (PCA) is used to identify the dominant sources of variation in asset returns, while clustering methods are employed to group assets with similar behavior. The resulting portfolios are evaluated against a naïve equal-weight benchmark to assess their risk and return characteristics.

## Repository Structure

* `python/` — Python implementation of the project.
* `r/` — R implementation of the project.

## Companion Chapter

The conceptual foundations, methodology, results, and discussion are presented in the corresponding chapter of the portfolio book:

**Unsupervised Learning for Asset Allocation**

The code contained in this repository is intended to complement the chapter and provide reproducible computational workflows for the analyses presented there.
