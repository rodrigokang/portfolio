# Customer Value and Retention Dashboard

Streamlit analytical demo for the portfolio project **Customer Value and Retention**.

The dashboard reuses precomputed outputs generated by the Python notebooks and allows interactive exploration of:

- Customer segmentation
- Churn prediction
- Customer lifetime value

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Demo credentials

- User: `demo`
- Password: `portfolio`

## Data inputs

The app reads CSV files automatically from the `datos/` folder:

```text
datos/
    customer-segmentation.csv
    customer-churn-prediction.csv
    customer-clv-prediction.csv
```

No file uploader is included. The dashboard does not retrain models or rerun machine learning pipelines.
