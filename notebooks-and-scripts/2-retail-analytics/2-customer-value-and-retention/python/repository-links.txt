**Supervised Regression Models**

The following regression algorithms are evaluated and compared throughout this project:

- Linear Regression
- Ridge Regression
- LASSO Regression
- Regression Tree
- Random Forest
- XGBoost
- K-Nearest Neighbors Regression (KNN Regression)
- Support Vector Regression (SVR)
- Bayesian Additive Regression Trees (BART)

These models were selected to represent a diverse set of supervised learning paradigms, including linear models, regularized regression, tree-based methods, ensemble learning, instance-based learning, kernel methods, and Bayesian machine learning approaches.
