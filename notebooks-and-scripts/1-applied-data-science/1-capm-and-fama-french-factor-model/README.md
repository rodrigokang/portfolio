# CAPM and Fama–French Models

This repository contains the implementation files accompanying the portfolio project **CAPM and Fama–French Models**, part of the book *Data Science Across Domains: From Methods and Models to Business Applications*.

The project investigates how asset pricing models explain the relationship between systematic risk and expected return. Starting from the Capital Asset Pricing Model (CAPM) and extending to the Fama–French three-factor framework, the analysis combines financial theory, statistical modeling, and empirical evaluation using historical market data.

## Repository Structure

* `python/` — Python implementation of the project.
* `r/` — R implementation of the project.

## Companion Chapter

The conceptual foundations, methodology, results, and discussion are presented in the corresponding chapter of the portfolio book *Data Science Across Domains: From Methods and Models to Business Applications*.

The code contained in this repository complements the chapter and provides reproducible computational workflows for the analyses presented in the study.
